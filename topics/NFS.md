
### Установка NFS на сервере <!-- HEAD -->

#### Установка NFS-сервера <!-- NAME -->

```CODE
apt-get install nfs-server                                                               
```

> Устанавливает сервер NFS для экспорта каталогов по сети

#### Создание каталога для экспорта <!-- NAME -->

```CODE
mkdir /nfs
chmod 777 /nfs
```

> mkdir(создать каталог); chmod 777(права rwxrwxrwx для всех пользователей)

#### Настройка экспортов в /etc/exports <!-- NAME -->

```CODE
/nfs 192.168.20.0/26(rw,sync,no_subtree_check)                                           
```

> /nfs(экспортируемый каталог); 192.168.20.0/26(разрешенная подсеть); rw(read-write, чтение и запись); sync(синхронная запись на диск перед ответом клиенту); no_subtree_check(отключить проверку подкаталогов, повышает производительность)

> Опции маппинга пользователей: root_squash(по умолчанию, root клиента мапится на nobody:nogroup, UID 65534); no_root_squash(root клиента = root сервера, небезопасно); all_squash(все пользователи клиента мапятся на анонимного); anonuid=1000(указать конкретный UID для анонимных пользователей); anongid=1000(указать конкретный GID для анонимных пользователей)

> Другие опции экспорта: ro(только чтение); async(асинхронная запись, быстрее но риск потери данных); subtree_check(проверка подкаталогов, безопаснее но медленнее)

#### Применение изменений <!-- NAME -->

```CODE
exportfs -ra 
```

> exportfs(управление таблицей экспортируемых NFS-каталогов); -r(re-export, перечитать /etc/exports); -a(all, применить ко всем каталогам)

### Установка NFS на клиенте <!-- HEAD -->

#### Установка NFS-клиента <!-- NAME -->

```CODE
apt-get install nfs-clients                                                              
```

> Устанавливает утилиты для монтирования NFS-каталогов

#### Добавление записи в /etc/fstab <!-- NAME -->

```CODE
192.168.30.3:/nfs /mnt/nfs nfs defaults 0 0                                              
```

> 192.168.30.3:/nfs(удаленный каталог в формате IP:путь); /mnt/nfs(точка монтирования); nfs(тип файловой системы); defaults(опции по умолчанию: rw,suid,dev,exec,auto,nouser,async); первый 0(dump, не создавать резервные копии); второй 0(fsck, не проверять ФС при загрузке)

#### Монтирование всех файловых систем из fstab <!-- NAME -->

```CODE
mount -a
```

> -a(all, смонтировать все файловые системы из /etc/fstab)

### Проверка подключения <!-- HEAD -->

#### Просмотр NFS-монтов <!-- NAME -->

```CODE
mount | grep nfs                                                                         
```

> mount(показать все смонтированные файловые системы); grep nfs(фильтр по типу nfs)

#### Проверка доступных экспортов на сервере <!-- NAME -->

```CODE
showmount -e 192.168.30.3                                                                
```

> showmount(показать информацию о NFS-экспортах); -e(exports, список экспортируемых каталогов с указанием разрешенных клиентов)

### Проверка работы NFS <!-- HEAD -->

#### Создание тестового файла на клиенте <!-- NAME -->

```CODE
cd /mnt/nfs                                                                              
touch txt                                                                                   
ls                                                                                          
```

> touch(создать пустой файл); ls(список файлов в каталоге)

#### Проверка на сервере <!-- NAME -->

```CODE
ls -l /nfs                                                                               
```
